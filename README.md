> **TRUSTex Contribution Simulator**
>
> This simulator shows how the financial contribution of a textile product is built under extended producer responsibility (EPR). It applies the equation developed in Task 4.2 of the TRUSTex project:
>
> Fee = ((NC + CC + SC) × PHAF − EDB + RSC + RA) × IAF + BWIC
>
> The user sees each term, its unit, its reference value, its source and the way it can be controlled. Three pieces serve as examples (a T-shirt, a pair of jeans and a blazer), each in two production cases: Europe and distant sourcing.
>
> **Status of the values.** All amounts are modelled. Each reference value carries a status in the inventory: measured, published, calculated, convention, illustration, weak source, or default at the ceiling. Where a value is missing, the simulator takes the ceiling of a reference value, and the inventory names the source that should replace it.
